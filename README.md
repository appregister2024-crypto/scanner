# Barcode Scanner

React Native + Expo ile hazırlanmış, Android ve iOS'ta çalışan çoklu barkod okuyucu.

## Özellikler

- QR kod okuma
- EAN, UPC, Code 39/93/128, PDF417, Data Matrix, Aztec ve benzeri barkod türleri
- Son okutulan değeri gösterme
- Geçmiş listesi
- Kopyalama ve açma eylemleri

## Çalıştırma

```bash
npm install
npm run start
```

Android için:

```bash
npm run android
```

iOS için:

```bash
npm run ios
```

## Not

Bu proje Expo tabanlıdır. Gerçek cihazda kamera ile test etmek en sağlıklı sonucu verir.
